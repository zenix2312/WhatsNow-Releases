# WhatsNow

Módulo root que integra notificações do WhatsApp à Now Bar de aparelhos Samsung Galaxy tecnicamente compatíveis.

**Versão beta:** [v0.5.0-beta.1](https://github.com/zenix2312/WhatsNow-Releases/releases/tag/v0.5.0-beta.1) · Mantenedor: **zenix2312**

[Código das versões](https://github.com/zenix2312/WhatsNow-Releases/releases)

## Compatibilidade

Compatibilidade confirmada em testes: Samsung Galaxy A07, Android 16, One UI 8.5 e KernelSU. Outros aparelhos precisam de testes; a existência visual da Now Bar não garante suporte técnico.

## Instalação

1. Baixe o ZIP de instalação e o SHA-256 na página de Releases.
2. Confira o checksum. Guarde uma versão anterior funcional e mantenha um método de recuperação.
3. Instale pelo gerenciador de módulos root compatível.
4. Verifique o diagnóstico no botão **Ação** do módulo e teste com notificações reais.
5. Em caso de falha ou reinícios do SystemUI, desative o módulo e use seu procedimento de recuperação.

## Limitações da beta

- Responder diretamente dentro do cartão continua desativado para preservar a estabilidade.
- Históricos com mensagens longas podem sofrer cortes.
- Compatibilidade com outros dispositivos, One UI e gerenciadores root ainda precisa ser verificada.

## Código e termos de uso

O código-fonte original é privado. Este repositório distribui apenas o módulo compilado e documentação. O ZIP contém scripts necessários à instalação, que ficam visíveis para quem o baixa. O pacote é fornecido para testes pessoais; redistribuição de versões alteradas ou com outra autoria exige autorização. Consulte [os termos](TERMS.md).

WhatsNow é um projeto independente, sem vínculo oficial com Samsung ou Meta.
